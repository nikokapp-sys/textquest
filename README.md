# TextQuest – Das verschwundene Wissen

Ein 2D-Lernabenteuer für Deutsch, Klasse 10 M. Ohne Anmeldung und ohne externe Abhängigkeiten.

## Spielorte

- Klassenzimmer 10b: Sachtexte mit Herrn Kapp
- Schulsozialarbeit: Rechtschreibstrategien
- Lehrerzimmer: Kommasetzung
- Schulbibliothek: Abschlussmission

## Spielen

Die Datei `index.html` im Browser öffnen oder GitHub Pages aktivieren.

Für GitHub Pages: **Settings → Pages → Deploy from a branch → main → / (root) → Save**.
Die Adresse lautet nach erfolgreicher Veröffentlichung: https://nikokapp-sys.github.io/textquest/

## Bedienung

WASD/Pfeiltasten: bewegen. E/Leertaste: ansprechen. Alternativ auf einen Weg tippen oder die Raumkarten öffnen.

Fortschritt und Antworten werden ausschließlich im Browser gespeichert. Ergebnisse können gedruckt oder als CSV exportiert werden. Freitextantworten werden anhand von Musterlösungen selbst eingeschätzt.
